Iqbal Terminal

Multi-session SSH client with PEM and PPK keys.

  • Ctrl+C copies the selection (or sends interrupt when nothing is selected)
  • Ctrl+V pastes  ·  Ctrl+Shift+F finds
  • Ctrl+= / Ctrl+- change font size  ·  Ctrl+wheel too
  • Ctrl+Shift+P pops a session out as a floating PiP window (stays on top)
  • Ctrl+Shift+E opens the rich text editor
  • Ctrl+Shift+W closes a tab  ·  Ctrl+PgUp/PgDn switch tabs
